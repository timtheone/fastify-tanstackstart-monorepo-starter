# Test through public seams

The Template recognizes three default test seams: pure exported logic under Vitest without infrastructure, the fully assembled Fastify application through `inject()` with Testcontainers PostgreSQL, and the running product through Playwright in a real browser. Tests assert observable behavior at those interfaces and do not mock or inspect internal Drizzle helpers, private application helpers, or collaborator call counts. Application operations receive direct tests only when they are themselves a genuine non-HTTP interface; otherwise Fastify integration tests exercise them through the First-Party API. This avoids duplicating the same behavior across implementation layers while preserving focused tests for pure logic and critical browser journeys.
