# Commit generated source artifacts

The generated Better Auth Drizzle schema, Drizzle migrations and metadata, Orval client, and TanStack Router route tree are committed rather than recreated only inside local or CI builds. Each artifact follows its owner's lifecycle instead of a universal generation command: the committed Better Auth schema is project-owned source, `pnpm db:generate` creates Drizzle migrations, `pnpm gen:openapi` reads the running Fastify server's OpenAPI endpoint directly and regenerates Orval output, and the TanStack compiler maintains the route tree during development and builds. The OpenAPI document is not committed because Fastify generates it from registered route schemas. Keeping the source artifacts reviewable lets developers and agents inspect contract and migration consequences directly; the accepted cost is generated diff churn, controlled by a no-manual-edits rule and appropriate drift checks. Ephemeral build output, caches, coverage, and test reports remain untracked.
